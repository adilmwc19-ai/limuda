# לימודא (Limuda)

![Version](https://img.shields.io/badge/version-2.0.0-blue) ![Next.js](https://img.shields.io/badge/Next.js-16-black) ![PWA](https://img.shields.io/badge/PWA-ready-5A0FC8) ![License](https://img.shields.io/badge/license-MIT-green)

**לימודא (Limuda)** היא אפליקציית ווב מתקדמת (PWA) ללימוד תורה ויהדות יומי. המיזם מציע ממשק מודרני, נקי ונטול הסחות דעת, המותאם במלואו למובייל ולמחשב, ומרכז במקום אחד את מסלולי הלימוד היומיים הנפוצים: **תנ"ך**, **משנה יומית**, **דף יומי**, **רמב"ם (משנה תורה)**, **ספר המצוות**, **תהילים יומי**, ועוד.

האפליקציה נבנתה עבור לומדים שרוצים שהלימוד היומי שלהם ייפתח באופן מיידי, יעבוד גם ללא חיבור לאינטרנט, וירגיש כאפליקציה טבעית בכל מכשיר — מחשב, אנדרואיד או iOS.

---

## תכונות מרכזיות (Key Features)

### 📖 מסלולי לימוד מגוונים
- **תנ"ך**, **משנה יומית**, **דף יומי**, **משנה תורה (רמב"ם)**, **ספר המצוות**, **תהילים יומי**, ומסלולים נוספים (חפץ חיים, קיצור שולחן ערוך, פרק שירה)
- טקסטים ותרגומים מסונכרנים ישירות מול [ה-API הרשמי של ספריא (Sefaria)](https://www.sefaria.org/), עם גיבוי חינני לקריאה גם ללא חיבור לרשת

### 🎨 התאמה אישית של חווית הקריאה
- שליטה מלאה בגודל הגופן, מקומפקטי ועד גדול מאוד
- ערכות נושא יום/לילה המותאמות לקריאה ארוכה
- מעקב התקדמות מקומי לכל מסלול לימוד, הנשמר על המכשיר

### 📱 חוויית PWA מתקדמת
- באנר התקנה חכם המובטח להופיע בכל הדפדפנים, במחשב ובנייד
- התקנה קלה כאפליקציה למסך הבית, ללא צורך בחנויות אפליקציות
- מצב אפליקציה עצמאית (standalone) אמיתי לאחר ההתקנה — ללא ממשק דפדפן
- עדכונים שקטים ברקע באמצעות Service Worker, ללא הודעות טעינה חוזרת מטרידות

### 🇮🇱 עברית אותנטית ונגישות
- המרת מספרי פרקים ופסוקים לגימטריה עברית תקנית
- הגנה מובנית מפני שיבושי תרגום אוטומטי של דפדפנים (Google Translate ואחרים, באמצעות `notranslate`)
- פריסת RTL (מימין לשמאל) מלאה בכל האפליקציה
- ניווט מקלדת ותמיכה בניגודיות ובסמנטיקה בהתאם לתקן **WCAG 2.1 AA**, כולל תמיכה מלאה בקוראי מסך

## ארכיטקטורה וטכנולוגיות

| שכבה | טכנולוגיה |
|---|---|
| Framework | [Next.js 16](https://nextjs.org/) (App Router) |
| שפה | [TypeScript](https://www.typescriptlang.org/) |
| עיצוב | [Tailwind CSS 4](https://tailwindcss.com/) |
| אייקונים | [Lucide Icons](https://lucide.dev/) |
| מקור נתונים | [Sefaria API](https://www.sefaria.org/) |
| אחסון / שרת | [Firebase](https://firebase.google.com/) |
| פריסה (Deployment) | [Vercel](https://vercel.com/) |

האפליקציה בנויה בהתאם למבנה App Router של Next.js (`src/app`), כאשר כל מסלול לימוד ממומש כנתיב (route) נפרד תחת `src/app/study/*`, לצד ספרייה משותפת של מתאמי נתוני ספריא ב-`src/lib`.

## הוראות התקנה והרצה מקומית

### דרישות מקדימות
- Node.js גרסה 18.18 ואילך
- npm (או yarn / pnpm / bun)

### התקנה

```bash
git clone https://github.com/<your-org>/limuda1.git
cd limuda1
npm install
```

### הרצה בסביבת פיתוח

```bash
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000) בדפדפן כדי לראות את האפליקציה פועלת.

### בנייה לסביבת production

```bash
npm run build
npm run start
```

## פריסה (Deployment)

לימודא מותאמת באופן אופטימלי לפריסה על [Vercel](https://vercel.com/), הפלטפורמה שנבנתה על ידי יוצרי Next.js.

1. דחפו (push) את המאגר ל-GitHub.
2. ייבאו את הפרויקט ל-[Vercel](https://vercel.com/new).
3. הגדירו את משתני הסביבה הנדרשים (ראו `.env.local`).
4. פרסו — Vercel יבצע בניה ואירוח אוטומטיים של אפליקציית ה-production.

למידע נוסף, ראו את [תיעוד הפריסה הרשמי של Next.js](https://nextjs.org/docs/app/building-your-application/deploying).
